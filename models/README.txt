Place the GGUF model used by the local AI server in this folder.

Default expected filename:
qwen2.5-1.5b-instruct-q4_k_m.gguf

Download link:
https://drive.google.com/file/d/1G9zDMnDXh1nBYblO3OPhTiROFFuCHuGS/view?usp=drive_link

The model file is not included in the repository because it may take up a large
amount of space. If you use another model or a different path, set the
MODEL_PATH variable before running START_LLAMA_SERVER.bat.
